# 1.8+ 跨设备同步与旧版升级

## 同步前提

- 多台电脑使用 Chrome，登录同一 Google 账号并启用 Chrome 的扩展/设置同步。原始书签需要另行开启 Chrome 书签同步。
- 每台电脑加载正式包的 `dist/`。正式包固定扩展 ID 为 `hakccklcdnjclaboolbceiebhaigebpo`，不依赖文件夹路径。不要把过渡包当作正式同步版本。
- 要求 Chrome 108+。无需自己的账号、服务器、API 密钥或额外网页访问权限。

## 旧版（1.7 及以前）升级

旧版没有固定扩展 ID；直接换成正式包可能被 Chrome 识别为另一个扩展。**先导出旧设置，再切换。不要先卸载旧版。**

1. 下载 `downloads/bookmark-grid-migration.zip`（无固定 key 的过渡包）。
2. 解压，用其中的 `dist/` 内容更新你原来加载扩展的目录，保持原路径；在 `chrome://extensions` 点击旧扩展的“重新加载”。如提示权限变更，按 Chrome 提示启用扩展。
3. 打开新标签页 → 设置 → 跨设备同步 → **导出设置**，保存 JSON 文件。
4. 停用过渡扩展，下载正式包 `downloads/bookmark-grid-dist.zip`，解压后加载其 `dist/`。核对扩展 ID 为上面的固定 ID。
5. 在正式版设置中 **导入设置**，选择刚才的 JSON。核对布局、名称、置顶，再在其他电脑安装同一正式包。
6. 设置页可点击“重试同步”。Chrome 接收数据后会显示“已交给 Chrome 同步”；另一台电脑的数据到达时间由 Chrome 决定。

备份包含布局、引擎/打开偏好和按网址关联的别名/置顶，不含原始书签树、使用次数或访问时间。首次切换扩展 ID 后，本机使用次数会在新扩展中重新累计；旧扩展未卸载时其原数据仍保留。不要同时启用两个新标签页扩展。

已经使用过 1.8 正式版的电脑，以后直接用新正式包更新原目录并重新加载即可，无需重复过渡流程。新电脑直接安装正式包。

## 1.9 本机背景

已经使用 1.8 正式版时，更新原 `dist/` 目录并重新加载即可，不需要再切换扩展 ID 或导入导出。设置 → 本机背景 → 选择背景图片；可调整深色遮罩、关闭背景或恢复纯色。

支持 JPEG、PNG、WebP（最多20MB/3200万像素），处理为最长边2560px、最多2MB的静态图。关闭开关会保留图片，恢复纯色会删除图片。图片、开关和遮罩只保存在本机，不同步、不进入设置备份；切换扩展 ID 时需在正式版重新选图。

## 数据规则

- 同步：列数、行列间距、文字/图标大小、搜索引擎、打开方式、置顶、自定义显示名称。
- 不同步：每条本机书签的使用次数/最近打开时间、当前页码、搜索输入，以及 1.9 新增的本机背景图片、开关和遮罩。背景也不包含在设置备份中，切换扩展 ID 后需重新选择图片。
- 网址以 Chrome Bookmarks API 提供的完整字符串匹配。路径、查询参数和 `#` 片段不同则分别处理；同一完整网址的多个副本共享置顶/名称，但打开次数仍按本机书签 ID 各自累计。
- Chrome 书签原始标题不被修改。删除仍仅删除选中的本机书签；对应 URL 的同步元数据保留，避免另一台电脑的书签丢失设置。
- 首次迁移只填充 Chrome 当前同步数据中没有的字段。自动迁移使用低优先级版本，迟到的云端用户修改仍优先；新设备不会上传默认值覆盖已有设置。
- 多设备同一字段同时离线修改时，按逻辑时间和设备标识确定胜者；不同字段独立合并，不提供跨设备原子事务。取消置顶和恢复原标题也会同步。
- 用户导入备份会替换文件中相同项目的值，其他项目保留，不删除原始书签；导入后仍需等待 Chrome 传播。

## 同步状态与限制

保存先写本机缓存和待发送队列，后台约 5 秒合并写入 Chrome 同步存储；服务 worker 暂停、失败或重启时由 alarm 再次处理。滑块连续调整不会逐事件写入同步存储。

“已交给 Chrome 同步”只代表 `chrome.storage.sync` 接收成功，不代表 Google 云端或其他电脑已收到；没有登录或断网时，Chrome 也可能先本地接收再延后传播。本插件无法检测 Google 登录、真实网络复制进度或其他电脑在线状态。

Chrome 同步存储限制：约 100KB 总量、每项 8KB、最多 512 项。数据采用 256 个网址分桶和独立设置桶，不会为每条书签创建独立 key。大量别名/置顶仍可能达到容量上限；此时显示同步错误，本机数据和待发送队列保留，不会声称成功。可先导出备份，再减少不需要的别名/置顶后重试；历史 URL 元数据保留会持续占空间，当前没有自动删除历史云端设置的功能。

原始书签树和使用记录不上传；同步内容包含偏好、别名、置顶及网址 SHA-256 标识，交给 Chrome 同步。网址摘要是匹配标识，不是加密或匿名保证。
