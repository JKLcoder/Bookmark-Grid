# 本地静态背景

用户确认：本地上传静态背景、深色遮罩、开关、恢复纯色；不做背景图片跨设备同步。背景相关偏好随本机图片保存，既有同步格式与固定扩展 ID 保持不变。

采用 IndexedDB 保存单张压缩后的图片与本机开关/遮罩，事务更新避免覆盖失败损坏旧背景；BroadcastChannel 通知其他标签页，背景作为固定装饰层，不参与高度/分页计算。首版支持 JPEG/PNG/WebP，转成静态 WebP，长边最多 2560px、结果最多 2MB；输入最多 20MB/3200万像素。遮罩默认 75%，范围65–90%，启用背景时增强辅助文字对比，搜索和设置保留实色。
