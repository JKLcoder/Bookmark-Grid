# 跨设备设置同步

已确认：Chrome 原生 storage.sync，同步布局/引擎/打开偏好、完整 URL 对应的置顶与别名；次数与最近使用仅保存在本机。同网址重复书签共享置顶/别名。

架构：后台单队列写入持久化缓存与待发送数据。URL SHA-256 标识，256 个分桶控制 key 数；每字段独立逻辑时间版本合并并保留 false/null 墓碑，防止旧设备恢复已取消的设置。云端优先迁移本机旧数据；读云端失败时推迟迁移。暂未出现于本机的书签元数据保留。

- [x] 核心双设备、不同本机 ID、重复 URL、离线重启、合并冲突、容量失败、旧数据迁移、导入导出测试。
- [x] 同步存储模块、后台路由、5 秒合并写入和 alarms 恢复队列。
- [x] 设置/别名写入后台，计数继续本机，置顶按 URL 读取与更新。
- [x] 设置面板增加准确同步状态、重试、迁移导出/导入。固定公钥 ID；交付无 key 过渡包与正式包。
- [x] 构建、全部测试、生产页面交互/分页与双设备浏览器验证；更新说明与 GitHub 下载包。

限制：storage.sync 接收不等于其他设备已收到，不能检测 Google 登录或网络复制完成。100KB 总量、8KB 单项、512 项限制需明确报告并保留待发送数据。原始书签树仍由 Chrome 自己同步。

验证：133 项测试、TypeScript/Vite 构建、页面/分页/交互/双设备模拟浏览器回归通过。代码审查发现的别名更新、失败后重试、迁移优先级和失败保存事务问题均增加回归并修复。真实 Google 跨电脑传播需用户自己的 Chrome 账号验收。
