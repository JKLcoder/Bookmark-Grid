# 自动分页实施计划

用户已确认：顶部搜索保持不变，书签按屏幕容量分页，搜索结果同样分页。

采用现有 React/CSS 网格，通过 ResizeObserver 测量可用区域及实际行高；不采用固定条数（无法适应窗口和字号）或 CSS 多栏（无法明确控制页边界）。底部保留分页控件空间。搜索变化与容量变化回到第一页；删除后限制页码到有效范围。保留现有排序、链接、编辑和置顶逻辑。不新增依赖，不发布环境。
