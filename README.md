# Bookmark-Grid
Chrome Plugin

轻量的 Chrome Manifest V3 新标签页扩展。将所有层级的书签扁平化为文字网格，支持跨设备偏好、置顶与自定义名称同步，实时搜索与书签变化同步。

## 开发与构建

需要 Node.js **22.12+**（本云环境使用 24.22.1）和 npm。

```bash
npm ci
npm test
npm run build
```

构建结果为 `dist/`，包括 Manifest、React 页面、静态资源和后台清理脚本。所有资源打包在本地，无 CDN 或自建后端。基础功能无需账号；跨设备设置同步使用你自己的 Chrome / Google 同步。书签筛选和使用记录在本地处理；仅在引擎模式主动提交时，将关键词交给设置中选择的搜索引擎。

`npm run dev` 可用于页面开发，但普通网页没有 Chrome Bookmarks API，会显示加载扩展的提示，不会伪造书签。验证真实行为请加载 `dist/`。修改后重新构建，在扩展页点击重新加载，并打开新标签页。

正式包固定扩展 ID：`hakccklcdnjclaboolbceiebhaigebpo`。多台电脑使用同一 Google 账号和 Chrome 同步，并加载同一正式包，即可同步布局、引擎/打开偏好、置顶和名称。**同一完整网址的副本共享置顶和名称；使用次数保留在本机。** 设置页可查看状态、重试、导出与导入。

正式版要求 Chrome 108+。本机保存与 Chrome 接收同步分开显示；插件无法确认其他电脑是否已收到。

## 在 Chrome 安装

也可直接下载仓库中的 [已构建扩展 ZIP](downloads/bookmark-grid-dist.zip)（在 GitHub 文件页点击 Download raw file），解压后按下面第 2–5 步加载解压出的 `dist/`，无需安装 Node.js。ZIP 对应本次提交的构建版本，修改源码后需要重新构建。

1. 运行 `npm ci` 和 `npm run build`。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目的 **dist 目录**，不是项目根目录。
5. 新建标签页；如 Chrome 提示新标签页变更，请保留此扩展。

已有其他新标签页扩展时，请先停用它们以免覆盖冲突。书签功能可离线使用；网页搜索和访问网站需要网络。安装不需要账号或 API 密钥。

## 使用

界面采用深色紧凑布局，每个 Item 在名称前显示与文字等大的小号网站图标，不展示域名或 URL。URL、域名和原路径仍可搜索；真实链接地址及原生点击行为保持不变。默认 6 列、行间距 4px、列间距 12px，文字与图标同为 16px。

- 自动读取全部书签，包括多层嵌套目录；保留重复 URL，不显示文件夹分组。
- 置顶书签优先，然后按累计打开次数、最近打开时间排序；相同时按中文友好的显示名称排序。全新安装尚无点击记录时按名称排序。
- 输入框左侧下拉切换“引擎 / 书签”，每次打开或刷新默认进入引擎模式。引擎模式不筛选书签，按 Enter 使用设置中选择的搜索引擎，在当前标签页打开结果；输入过程不发送关键词，不提供在线联想。书签模式实时筛选自定义名称、原标题、URL、域名和原文件夹路径，Enter 不提交网页搜索。切换模式保留文字，清空恢复全部。
- 点击书签按设置在当前或新标签页打开（默认当前标签页）；Ctrl / Command 点击、中键点击仍由原生链接处理。新标签页不保留 opener。
- 悬停或 Tab 聚焦 Item 出现编辑和置顶按钮，触屏上按钮始终可见。
- 编辑仅改变显示名称；留空或点击“恢复原标题”删除该别名。无别名时原标题变化会立即反映。
- 设置入口支持列数（自动或 1–12 列）、行间距（0–32px）、列间距（0–48px）、文字与图标的统一大小（12–28px），调整即时预览并保存在本机，可一键恢复默认。窄屏会自动减少实际列数，避免横向溢出。

## 本机背景（1.9）

设置 → **本机背景** → 选择背景图片。支持 JPEG、PNG、WebP，最多 20MB / 3200 万像素；自动转为静态 WebP，长边最多 2560px，保存结果最多 2MB。图片居中铺满，宽窄窗口会裁切边缘。

- 默认纯色；选择图片后自动启用。深色遮罩默认 75%，可在 65–90% 调整，保持文字清楚。
- 关闭“启用背景图片”会保留图片，便于以后重新打开；“恢复纯色”删除本机图片并恢复默认遮罩。
- 图片、开关及遮罩保存在本机 IndexedDB，同一电脑的标签页会实时更新；**不写入 Chrome 同步、不包含在设置导出文件中**。
- 更换图片失败保留原背景；图片损坏或无法加载时显示纯色。搜索、分页计算和书签顺序不受装饰层影响，搜索框和设置面板保持实色。
- 本功能没有网络壁纸请求、不新增权限。使用本机 Blob URL 显示处理后的图片，CSP 仅增加 `img-src blob:`。

已经使用 1.8 正式版时，直接更新原 `dist/` 目录并重新加载；固定扩展 ID 保持一致，无需再次过渡迁移。旧版升级流程仍见下方链接。

背景回归：`npm run build && npm run test:background`，覆盖真实浏览器下的压缩、重载、多标签页、设备隔离、失败保护、损坏恢复和 CSP。

## 自动分页

书签区域按窗口的可用高度、实际列数、字号和行间距自动计算每页容量，超出的书签放到下一页。上方搜索框保持原样，底部显示“上一页 / 页码 / 下一页”；只有一页时隐藏翻页控件。无需通过纵向滚动查看大量书签。

书签搜索会对全部书签筛选后再分页；修改搜索条件会回到第一页。调整窗口大小或布局导致每页容量变化时也回到第一页，删除书签后页码自动保持在有效范围内。翻页沿用现有置顶和网站排序，原生点击、编辑和删除行为保持不变。

分页浏览器回归：`npm run build && npm run test:pagination`，验证 257 个书签逐页完整遍历、搜索重置、窗口/字号/间距变化及页面无溢出。

## 操作反馈与键盘焦点

设置保存失败时，恢复提示在分页下方占用实际布局空间，书签区自动减少每页条数，翻页按钮保持可见、可点击。“重试保存”和“撤销未保存更改”仍可使用。

置顶或取消置顶成功后，书签数量右侧显示成功状态及“查看”按钮。若书签移到其他页，键盘焦点会落到“查看”；点击后跳到目标页并聚焦该书签的图钉按钮。保存失败不会显示成功状态。

编辑显示名称时自动聚焦输入框；退出后恢复到原书签的编辑按钮。重命名导致排序换页时会定位到新页；书签删除后，焦点移到当前页的第一条书签，无剩余书签时移到搜索框。删除确认仍默认聚焦“取消删除”。

交互回归：`npm run build && npm run test:interaction`。使用真实 Chromium 与模拟 Chrome API，覆盖错误提示与分页、置顶反馈和定位、编辑/删除焦点，以及重命名后异步刷新换页。

## 搜索与打开偏好

设置中可选择默认搜索引擎：百度、Google，或“跟随 Chrome”（兼容旧版本的默认值）。百度使用 `https://www.baidu.com/s?wd=...`，Google 使用 `https://www.google.com/search?q=...`；中文和特殊符号均进行 URL 编码。输入时不请求搜索引擎，仅主动提交时导航。该设置只影响插件内搜索，不修改 Chrome 自身配置。

“网站打开方式”提供当前标签页和新标签页，控制书签点击，默认当前标签页。搜索结果始终在当前标签页打开。原生 Ctrl/Command/Shift 点击与中键行为保留。两项偏好保存在本机并交给 Chrome 同步，刷新后保留；恢复默认会一并恢复为“跟随 Chrome”和“当前标签页”。无需新增权限。

## 使用频率、置顶与同站聚合

- 只记录从本插件左键、键盘激活、Ctrl/Command/Shift 点击及中键发起的打开操作，不读取浏览器历史，也不记录其他入口的访问。次数不代表网页加载成功或访问时长。
- 升级前的使用次数无法补算，新版启用后从 0 开始累计；重复 URL 按不同书签 ID 独立记录。
- 悬停或键盘聚焦时点击图钉可置顶/取消置顶，已置顶书签保留图钉标记；所有书签仍在同一个网格中。
- 置顶书签始终在最前面，其余书签按网站聚合相邻显示，仍然使用同一个扁平网格，不增加分组标题或折叠。网站按全部书签的总打开次数（含该站置顶书签）排序，网站内按单条次数排序；次数相同则按最近使用时间、中文友好的名称顺序排序。
- 网站按域名识别，忽略 HTTP/HTTPS、端口、路径及开头的 `www.`；其他不同子域名独立，非网页或无效地址按单条处理。重复网址保留，搜索仅筛选完整排序，不重新计算网站频率。
- 置顶立即改变排序；点击次数变化在下次新开或刷新页面后影响排序，避免当前页面的目标突然移动。
- 右键菜单本身不计数；通过浏览器右键菜单选择打开链接不在可靠统计范围内。
- 后台队列协调多标签页写入，统计失败不阻止原生打开。浏览器强制关闭前尚未完成的写入仍可能丢失。
- 本地 `usage:<id>` 保存使用次数和最近打开时间，旧版本中的 `pinned` 仅用于迁移；实际置顶按 URL 同步读取，不上传次数或完整书签树。删除书签/目录会清理本机记录，保留该 URL 的云端设置。

## 数据与权限

网站小图标通过 Chrome 自带的 `/_favicon/` 接口读取，需要 `favicon` 权限；本版本整体要求 Chrome 108+。不使用 Google S2 或其他远程图标服务，不会把书签 URL 发给第三方图标服务。无可用图标、加载失败或非 HTTP(S) 书签使用随扩展打包的通用图标。文字与图标严格使用相同的 CSS 像素尺寸；旧版本没有此设置时自动使用 16px。

申请 `bookmarks`、`storage`、`favicon`、`search`、`alarms`，没有 `history`、`tabs` 或 `host_permissions`。选择“跟随 Chrome”时通过 `chrome.search.query` 使用浏览器默认搜索引擎；选择百度或 Google 时，明确提交后导航到所选引擎的搜索结果地址，不修改 Chrome 默认引擎；书签读取使用 `chrome.bookmarks.getTree()` / `get()` 并监听 `onCreated`、`onChanged`、`onMoved`、`onRemoved`，保存自定义名称不修改原始标题；只有用户在编辑弹窗中进入“删除书签”并二次确认后，才调用 `chrome.bookmarks.remove(id)` 删除原始书签。

布局和名称保留 `layout:*` / `name:<id>` 本机镜像，方便即时预览和离线读取。后台维护 `sync:database:v1` 持久化缓存及待发送队列，将完整网址摘要对应的名称/置顶和布局偏好分桶写入 `chrome.storage.sync`。字段独立版本合并，取消操作保留墓碑，避免旧设备恢复已取消的设置；暂未出现在本机的 URL 不会被清理。

后台在书签新增、网址变更、同步到达时更新本机镜像；删除时只清理本机 ID 的名称/次数。跨设备信息与升级步骤、容量和同步状态限制见 [完整说明](docs/settings-sync.md)。

## 1.5 界面优化

沿用已确认的紧凑原型：压缩顶部留白，保留纯名称网格；搜索按钮和当前搜索引擎始终可见，按 `/` 快速定位搜索框。置顶与编辑按钮在悬停或键盘聚焦时显示，触屏始终显示。

设置中的列数是期望列数，实际列数随窗口宽度和字号调整，面板会显示当前列数。文字和图标保持同样大小；较大字号和触屏会减少列数以保护名称可读性。布局与搜索/打开设置分别恢复默认。

偏好设置即时预览并自动保存。页面显示保存状态；失败提示在关闭设置后仍保留，可重试或撤销未保存的偏好改动。设置面板支持 Escape、Tab 边界和点击外部退出。1.8 保留即时预览及错误恢复，并新增设置同步；升级需要按上面的固定 ID 迁移步骤操作。

## 删除书签

悬停书签并点击编辑按钮，在弹窗底部选择“删除书签”。核对名称与网址后，点击“确认删除”。这会同时删除 Chrome 书签管理器中的原始书签，无法在本插件内撤销。默认聚焦“取消删除”，可通过取消按钮或 Escape 返回编辑。

只删除选中的书签 ID，同网址的其他书签保持不变。删除成功后会同步更新网格，后台清理对应 ID 的本机名称镜像与使用记录，按 URL 保存的同步名称/置顶保留给其他副本或设备。失败会保留确认弹窗并提示重试；提交期间禁止重复操作。不支持批量或文件夹删除，不新增权限。
